# PROJECT: WILDLANDS

An original first-person 3D survival-adventure for Android, set on the fictional tropical island of Verdana.

## Current stage
**Planning and prototype setup.** The first playable milestone is a small jungle test area with first-person movement, mobile touch controls, one interaction, and a basic pause menu.

## Design goals
- Atmospheric tropical environments.
- Exploration and story told through locations and clues.
- Touch controls designed for Android.
- Scalable visuals and performance testing on real devices.
- Original characters, locations, story, and assets.

## Project documentation
- [Game Design Document](Docs/GAME_DESIGN.md)

## Planned technology
- Unity
- Universal Render Pipeline (URP)
- Android build target

## Roadmap
1. Set up the Unity project and Android build.
2. Build a compact test environment.
3. Add first-person movement and touch controls.
4. Add interaction and the first story clue.
5. Test performance before expanding the world.

The full game scope and final install size will depend on development and device testing.
